OpenQuire is an open-source PDF toolkit for the browser and desktop. It brings document tools into one workspace, with PDF processing handled on the user's device through MuPDF compiled to WebAssembly.

## A clear boundary around documents

Document processing and optional AI features have different privacy implications, so they need different boundaries. Local PDF operations run on the device. AI features are optional: requests go to the provider the user chooses, with consent for each request.

## Building in the open

The [public repository](https://github.com/akilfernando/openquire) contains the implementation, setup instructions, and current project status.
