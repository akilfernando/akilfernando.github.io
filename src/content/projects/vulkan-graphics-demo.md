I built this real-time renderer in C++ to learn Vulkan. The project involved setting up GPU queues, memory, synchronization, and graphics pipeline state explicitly.

Working through those steps helped me understand operations that OpenGL and graphics drivers handle automatically, and how rendering commands and resources reach the GPU.

I wrote about this project and my earlier OpenGL flight simulator in [Learning graphics by writing the renderer yourself](/blog/learning-graphics-from-scratch/).
